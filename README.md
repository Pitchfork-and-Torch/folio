# Folio

Night archive of ongoing Pitchfork-and-Torch research desks.

Live: https://folio.jonbailey.xyz/

This site is a full-canvas 3D hall. Scroll walks the aisle. The notes themselves stay on GitHub.

## Desks

- [liber-research](https://github.com/Pitchfork-and-Torch/liber-research) - Liber Primus hypothesis lab. Not a solve.
- [voynich-research](https://github.com/Pitchfork-and-Torch/voynich-research) - Beinecke MS 408 notes. Not a translation.
- [INSTAR](https://instar.jonbailey.xyz/) - Desk 03, the school. Seven molts. Not a recruiter.

## Honesty

No new Liber Primus plaintext. No Voynich language, plant, or crib. Hall pages are invented set dressing.

## Stack

Vite, React, Three.js (WebGPU first, WebGL fallback), React Three Fiber, Lenis, Motion, Zustand.
